## Bối cảnh
GitHub Free, ruleset yêu cầu check luôn có kết quả → không dùng `paths:` ở mức workflow. Deploy thủ công nên CI chỉ build + push image. Nguồn: `blueprint.md` §4, `quality-standards.md` §2–3, nghiên cứu GitHub Actions.

## Phạm vi
Làm:
- `.github/workflows/ci.yml`: jobs `setup` (cache pnpm + uv), `lint`, `contract`, `test-backend`, `test-web`, `test-mobile`, `build`, `deps-review`, `scope-check`; mỗi job dùng `turbo run … --affected` / `dorny/paths-filter` để bỏ qua nội bộ nhưng vẫn success; `concurrency` theo PR
- `release.yml`: on push `main` → build + push `ghcr.io/<org>/genetics-{api,web,mobile}:sha-<sha>`; on tag `v*` → `:vX.Y.Z`
- `nightly.yml`: e2e + visual + `pnpm audit` / `pip-audit` (warn)
- `dependabot.yml`: pnpm, uv, docker, github-actions; groups minor/patch; cooldown mặc định
- `scope-check`: script đọc `Task:` trong PR body → `allowed_paths` từ task file → diff → gắn nhãn `out-of-scope` nếu lệch
- Labels: `contract`, `api-breaking`, `deps-approved`, `shared`, `visual-change`, `out-of-scope`, `e2e` (script tạo qua `gh`)

Không làm:
- Không workflow deploy / SSH (deploy thủ công theo `docs/ops/deploy-vm.md`)
- Không secret production trong GitHub

## Tiêu chí chấp nhận
1. Cho PR chỉ sửa `docs/` · Khi CI chạy · Thì mọi required check báo success trong < 5 phút
2. Cho PR đổi `pnpm-lock.yaml` không nhãn `deps-approved` · Thì job `deps-review` fail
3. Cho PR body `Task: T0303` và diff chạm `apps/web/` · Thì nhãn `out-of-scope`
4. Khi push tag `v0.1.0` · Thì 3 image có tag `v0.1.0` trên GHCR
